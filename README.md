# Proyecto 2 - Analisis Exploratorio

Repositorio autocontenido para el Proyecto 2 del curso CC3084 - Data Science.

## Estructura

```text
src/                 Codigo reproducible y pipeline por definir
notebooks/           Exploracion y analisis exploratorio
data/raw/            Datos originales, nunca se modifican
data/processed/      Datos generados por el pipeline, no versionados
codebook.md          Diccionario del dataset final y decisiones de limpieza
requirements.txt     Dependencias minimas del proyecto
```

Las etapas del pipeline, las dependencias y la documentacion del dataset se
definiran despues de la inspeccion inicial de los datos.
